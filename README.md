# 🌆 OpenGL City & Nature Scenes (GLUT)
This project is a collection of animated and interactive scenes built using OpenGL with GLUT. It showcases creative visual storytelling through 2D and 3D environments, combining elements of city life and nature with smooth transitions and animations.

🎨 Scenes Included:
🌄 Countryside Morning – Hills, trees, sunrise, and animals in motion

🏙️ City in the Afternoon – Roads, buildings, animated vehicles, pedestrians, and park

🌅 Beach at Sunset – Ocean waves, sun setting, boat animation, and birds flying

🌌 Night in the Forest – Starry sky, glowing fireflies, and peaceful wildlife

🔧 Features:
🚗 Animated vehicles (cars, buses, boats)

🌧️ Realistic rain and splash effects (triggered on road/river only)

🐟 Fish and wildlife animation

💡 Lampposts, benches, rivers, sky, and rail tracks

⌨️ Keyboard interaction for switching scenes and toggling effects

🧰 Technologies Used:
C/C++ with OpenGL and GLUT

Coordinate system: 500×500 and 800×600 depending on scene

Modular design using custom functions for objects like buildings, trees, fish, and vehicles

This project is ideal for learning graphics programming, scene design, and animation with OpenGL/GLUT.
